# ImageZoneEditor

Кроссплатформенный редактор зон на растровых изображениях (Avalonia UI + MVVM + ImageSharp + OpenCV).

## Возможности

- Открытие изображения через диалог или аргумент командной строки.
- Автоматическое вписывание изображения в окно с сохранением пропорций.
- Зум колесом мыши и панорамирование (полосы прокрутки / средняя кнопка мыши).
- Добавление, выделение, перемещение, изменение размера (4 угловых маркера) и поворот зон.
- Неразрушающие фильтры и цветокоррекция для каждой зоны: яркость, контраст,
  насыщенность, оттенок, гамма, ч/б, сепия, инверсия, размытие, резкость, виньетка.
- Предпросмотр фильтров прямо на холсте: оригинальное изображение не изменяется.
- Фильтры применяются к пикселям только при экспорте (файл или буфер обмена).
- Автозагрузка зон из `<имя_изображения>.json` при открытии изображения.
- Сохранение и загрузка зон в JSON (System.Text.Json); настройки фильтров хранятся вместе с зоной.
- Экспорт выбранной зоны или всех зон в PNG без потерь — в файл или буфер обмена.
- При экспорте повёрнутой зоны содержимое выравнивается по её локальным осям,
  после чего к нему применяются фильтры.

## Требования

- .NET SDK 10.0 или новее (`net10.0`) — проверка: `dotnet --list-sdks`.
- 64-битная Linux-система (x64): пакет `OpenCvSharp4.official.runtime.linux-x64`
  содержит нативные библиотеки только под x86_64.
- GTK 3 — обязательная зависимость нативной библиотеки OpenCV (фильтры зон).
- XDG Desktop Portal с бэкендом под ваше окружение: через него Avalonia открывает
  диалоги «Открыть», «Сохранить» и выбора папки.
- Fontconfig и хотя бы один системный шрифт (шрифт Inter поставляется с приложением).

Avalonia использует X11-бэкенд, поэтому в Wayland-сессиях приложение работает
через XWayland (`xorg-xwayland`). Буфер обмена обслуживается самим Avalonia —
`xclip` или `wl-copy` не требуются.

### Установка зависимостей

EndeavourOS / Arch Linux:

```bash
sudo pacman -S --needed dotnet-sdk gtk3 fontconfig freetype2 \
    ttf-dejavu xdg-desktop-portal

# бэкенд портала выбирается по рабочему окружению:
sudo pacman -S --needed xdg-desktop-portal-gtk         # GNOME, XFCE, Cinnamon, MATE
# sudo pacman -S --needed xdg-desktop-portal-kde       # KDE Plasma
# sudo pacman -S --needed xdg-desktop-portal-hyprland  # Hyprland
# sudo pacman -S --needed xdg-desktop-portal-wlr       # sway, river и другие wlroots
```

Debian / Ubuntu:

```bash
sudo apt install dotnet-sdk-10.0 libgtk-3-0 fontconfig fonts-dejavu-core \
    xdg-desktop-portal xdg-desktop-portal-gtk
```

Проверка, что все нативные зависимости разрешаются (после первой сборки вывод
обеих команд должен быть пустым):

```bash
ldd bin/Debug/net10.0/runtimes/linux-x64/native/libOpenCvSharpExtern.so | grep "not found"
ldd bin/Debug/net10.0/runtimes/linux-x64/native/libSkiaSharp.so | grep "not found"
```

## Сборка и запуск

```bash
git clone https://github.com/AnceLost/ImageZoneEditor.git
cd ImageZoneEditor

dotnet restore   # скачивает NuGet-пакеты, включая нативные библиотеки OpenCV
dotnet build

dotnet run
# или сразу с изображением
dotnet run -- /path/to/image.png
```

Если `dotnet build` падает с ошибкой `NETSDK1045`, установлен SDK старше 10.0 —
проверьте `dotnet --list-sdks`.

## Управление

| Действие | Как |
| --- | --- |
| Открыть изображение | Кнопка «Открыть» или `Ctrl+O` |
| Добавить зону | Кнопка «+ Зона» или `Ctrl+D` |
| Удалить выбранную зону | Кнопка «Удалить» или `Delete` |
| Сохранить JSON | Кнопка «Сохранить JSON» или `Ctrl+S` |
| Переместить зону | Перетаскивание внутри зоны |
| Изменить размер | Перетаскивание углового маркера |
| Повернуть зону | Перетаскивание круглого маркера над зоной |
| Настроить фильтры | Выбрать зону в списке справа и двигать ползунки в блоке «Фильтры» |
| Сбросить фильтры зоны | Кнопка «Сбросить» в блоке «Фильтры» |
| Зум | Колесо мыши / кнопки «−» и «+» |
| Вписать в окно | Кнопка «Вписать» |
| Панорамирование | Средняя кнопка мыши или полосы прокрутки |

## Фильтры зон

- Панель «Фильтры» находится справа под списком зон и относится к выбранной зоне.
- Мастер-чекбокс «Включить фильтры» временно отключает все эффекты, сохраняя их значения.
- Превью перерисовывается с задержкой ~200 мс после изменения ползунка и работает
  на уменьшенной копии изображения, поэтому остаётся отзывчивым на больших файлах.
- Диапазоны: яркость/контраст/насыщенность −100…100, оттенок −180…180°,
  гамма 0.2…3, размытие 0…20, резкость/виньетка 0…100.
- Настройки фильтров сохраняются в JSON рядом с координатами зоны. Старые JSON
  без блока `Filters` открываются с нейтральными значениями (изображение не меняется).

JSON-файл зон хранится рядом с изображением и имеет то же имя с расширением `.json`.
